# Fraud Detection MLOps 🚀

An end-to-end fraud detection system built using Machine Learning and MLOps practices.

The project focuses on taking a fraud detection model from data preparation and experimentation to model tracking, API serving, testing, and containerization.

------

## 📌 Project Overview

This project uses transaction data to detect potentially fraudulent transactions.

The system includes:

- Exploratory Data Analysis
- Data preprocessing
- Machine Learning model training
- Class imbalance handling
- Model evaluation
- Threshold tuning
- MLflow experiment tracking
- Production model pipeline
- FastAPI prediction API
- Automated API testing
- Docker containerization
